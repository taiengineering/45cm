## 결정

### Phase 1만 먼저 실행한다

법령검색 페이지(WO-MKT-001~006)를 먼저 구현하고, 검색 노출과 유입 데이터를 확인한 후 Phase 2(무료진단)로 진행한다.

### 근거

Phase 1이 없으면 고객이 TAI를 발견할 수 없다. Phase 2(무료진단)는 발견 이후에만 의미가 있다. Phase 1의 검색 데이터가 Phase 2~4의 설계를 개선한다.

### Phase 1 WO 목록

WO-MKT-001: 법령 데이터 API 엔드포인트
WO-MKT-002: 법령 목록 페이지
WO-MKT-003: 법령 상세 페이지
WO-MKT-004: 의무 상세 페이지
WO-MKT-005: SEO 기본 설정
WO-MKT-006: 무료진단 CTA 배치

### Phase 2 진입 조건

Phase 1 완료 후 최소 2주간 검색 데이터를 수집한다. 검색 노출이 확인되면 Phase 2를 시작한다. 검색 노출이 없으면 Phase 1을 개선한다.
