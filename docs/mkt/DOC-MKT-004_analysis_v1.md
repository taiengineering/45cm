> 목표: "사용자가 TAI를 찾지 않아도 TAI를 만나게 한다."

이 단계는 Analysis이다. 문제도출이나 해결책을 작성하지 않는다.

---

## 분석 대상 (Fact)

현재까지 조사된 사실을 정리하면 다음과 같다.

- 사용자는 SaaS를 찾지 않는다.
- 사용자는 자신의 업무를 해결하려고 한다.
- 사용자는 자신의 언어를 사용한다.
- 사용자는 Google, AI, 커뮤니티, 정부사이트 등 여러 경로를 이용한다.
- 사용자는 서비스를 찾는 것이 아니라 답을 찾는다.
- 서비스는 문제 해결의 수단이다.

---

## Analysis 01: 공통 목적 분석

조사된 모든 행동을 비교하면 Google → ChatGPT → 커뮤니티 → 정부사이트 → 협회가 서로 다른 행동처럼 보이지만, 행동의 목적은 동일하다.

사용자는 서비스를 찾기 위해 이동하는 것이 아니라 자신의 문제를 해결하기 위해 이동한다.

**Key Point 01**: 사용자의 행동을 결정하는 기준은 서비스가 아니라 문제 해결이다.

---

## Analysis 02: 검색 대상 분석

조사 결과에서 검색 대상은 서비스명이 아니라 업무, 법령, 점검, 의무, 절차, 체크리스트 등이다.

사용자는 제품을 검색하는 것이 아니라 업무를 검색한다.

**Key Point 02**: 검색 행동은 제품 중심이 아니라 업무 중심으로 형성된다.

---

## Analysis 03: 채널 비교

Google, AI, 커뮤니티, 정부, 협회 모두 채널은 다르다. 그러나 채널이 달라도 사용자가 얻으려는 것은 동일하다 — 정답, 방법, 확인, 판단.

채널은 다르지만 사용자의 목적은 동일하다.

**Key Point 03**: 채널은 사용자의 행동을 결정하지 않는다. 목적이 채널을 선택하게 만든다.

---

## Analysis 04: 언어 분석

사용자는 법정점검, 안전관리, 산안법, 과태료와 같이 자신의 업무 언어를 사용한다. 서비스는 브랜드명, 기능명, 상품명으로 설명하려고 한다.

사용자와 서비스는 동일한 대상을 서로 다른 언어로 표현한다.

**Key Point 04**: 사용자의 언어와 서비스의 언어는 일치하지 않는다.

---

## Analysis 05: 행동 흐름 분석

사용자의 행동을 시간순으로 보면: 문제 발생 → 답을 찾음 → 여러 경로 이동 → 판단 → 행동.

서비스는 행동의 출발점이 아니라 행동 과정에서 만나는 하나의 수단이다.

**Key Point 05**: 서비스는 사용자의 여정을 시작시키지 못한다. 사용자의 문제만이 여정을 시작시킨다.

---

## Analysis 결과

| Key Point | 내용 |
|---|---|
| KP-01 | 사용자의 행동 기준은 서비스가 아니라 문제 해결이다. |
| KP-02 | 검색은 제품 중심이 아니라 업무 중심이다. |
| KP-03 | 채널은 목적에 의해 선택된다. |
| KP-04 | 사용자 언어와 서비스 언어는 다르다. |
| KP-05 | 사용자의 여정은 문제에서 시작되며 서비스에서 시작되지 않는다. |
