핵심 발견: 무료진단은 관계의 시작점 중 하나이며, 관계의 종착점은 아니다. 산업안전 서비스와의 첫 관계는 검색, 열람, 다운로드, 질문, 상담, 진단, 신청 등 여러 형태로 존재한다.

첫 관계 유형 12가지: (1) 발견(검색 결과 확인, 식별 낮음), (2) 열람(법령/FAQ 보기, 식별 낮음), (3) 검색(키워드/질문 입력, 낮음~중간), (4) 다운로드(점검표/가이드 저장, 낮음~중간), (5) 즐겨찾기(자료 저장, 중간), (6) 질문(간단 질의 등록, 중간~높음), (7) 상담(전화/인터넷 문의, 높음), (8) 진단(사업장 정보 입력, 높음), (9) 신청(컨설팅/지원사업, 높음), (10) 회원가입(계정 생성, 높음), (11) 공유(결과/문서 전달, 직접 식별 불확실), (12) 재방문(업데이트/주기 확인, 중간~높음).

관계 깊이 단계: 발견 → 열람 → 검색 → 다운로드/저장 → 질문 → 진단 → 상담 → 신청 → 실행 → 반복 방문. 단, 모든 사용자가 이 순서대로 이동하지는 않음.

첫 관계 분류: 첫 발견(검색 결과/AI 답변/공유 문서), 첫 이용(법령 검색/FAQ/체크리스트/무료진단/질문), 첫 식별(회원가입/상담/이메일/전화/신청서), 첫 실행(점검표 작성/교육 신청/컨설팅 참여), 반복 관계(법령 개정/정기점검/교육일정/재진단).

확인된 사실 8가지: (1) 첫 관계는 여러 형태 존재, (2) 공식 서비스도 FAQ/자료검색 먼저 → 추가 상담 연결 구조, (3) 다운로드 자료는 기업 내부에서 계속 사용, (4) 상담은 단순 질문과 법령 검토가 다른 깊이, (5) 컨설팅 신청은 단계적으로 깊어짐, (6) 첫 관계가 반드시 식별 가능 행동일 필요 없음, (7) 무료진단은 여러 첫 관계 중 하나, (8) 한 사용자의 결과 공유로 관계가 개인에서 조직으로 확대 가능.
