## 실행 원칙

모든 작업은 조사 → 문제 파악 → 해결책 → 실행 → 검증 순서를 따른다. 조사 없이 실행하지 않는다. 하나의 작업지시서는 하나의 검증 가능한 결과를 만든다. 작업 완료 기준은 실측 데이터로 판정한다.

---

## Phase 1: 법령검색 페이지 (SPEC-MKT-001)

### WO-MKT-001: 법령 데이터 API 엔드포인트

법령엔진(leg-prod) 데이터를 웹 페이지에서 조회할 수 있는 API 엔드포인트를 생성한다. 법령 목록, 법령 상세(조문), 의무 목록, 의무 상세를 반환한다.

PASS: API 호출 시 법령/의무 데이터가 정확히 반환된다.

### WO-MKT-002: 법령 목록 페이지

taieng.co.kr (또는 45cm.com)에 /laws 페이지를 생성한다. 주요 법령 목록, 조문 수, 적용 대상, 최종 개정일을 표시한다.

PASS: 페이지가 렌더링되고 검색엔진에 색인된다.

### WO-MKT-003: 법령 상세 페이지

/laws/{id} 페이지를 생성한다. 법령명, 조문 목록, 의무 요약, 처벌 기준, 시행일, 원문 링크를 표시한다.

PASS: 법령 상세 정보가 정확히 표시되고 출처가 명시된다.

### WO-MKT-004: 의무 상세 페이지

/obligations/{id} 페이지를 생성한다. 의무명, 근거 조문, 적용 대상, 수행 방법, 주기, 처벌을 표시한다.

PASS: 의무 정보가 법령엔진 데이터와 일치한다.

### WO-MKT-005: SEO 기본 설정

sitemap.xml, robots.txt, Schema.org 구조화 데이터, canonical URL을 설정한다.

PASS: Google Search Console에서 색인 요청이 수락된다.

### WO-MKT-006: 무료진단 CTA 배치

법령/의무 페이지에 "우리 사업장에 적용되는지 확인하기" CTA를 배치한다.

PASS: CTA 클릭 시 무료진단 페이지로 이동한다.

---

## Phase 2: 무료진단 셀프서비스 (SPEC-MKT-002)

### WO-MKT-007: 진단 입력 UI

KSIC 선택 → 시설/설비/공정/작업 입력 UI를 생성한다. 최소 KSIC만으로도 기본 결과를 제공한다.

PASS: 사용자가 KSIC를 선택하면 결과 미리보기가 표시된다.

### WO-MKT-008: 진단 결과 미리보기

Applicable Rule 수, Applicable Obligation 수, 주요 의무 3~5개 미리보기를 표시한다.

PASS: 실제 법령엔진 데이터 기반 결과가 표시된다.

### WO-MKT-009: 전환 게이트

전체 결과는 이메일 입력 또는 회원가입 후 제공한다. Excel 다운로드 옵션을 제공한다.

PASS: 이메일 입력 후 전체 결과가 표시되거나 Excel이 다운로드된다.

### WO-MKT-010: 행동 데이터 수집

페이지 방문, 진단 시작, KSIC 선택, 속성 입력, 결과 열람, 이메일 등록, 재방문 이벤트를 기록한다.

PASS: 각 이벤트가 DB에 기록된다.

---

## Phase 3: SEO 콘텐츠 자동화 (SPEC-MKT-003)

### WO-MKT-011: 콘텐츠 템플릿 설계

10가지 수요군(INV-MKT-007)에 대응하는 페이지 템플릿을 설계한다.

PASS: 템플릿이 법령엔진 데이터를 기반으로 페이지를 생성한다.

### WO-MKT-012: 자동 생성 파이프라인

법령엔진 DB → 템플릿 → 페이지 생성 → sitemap 갱신 파이프라인을 구축한다.

PASS: 법령 데이터 변경 시 페이지가 자동 재생성된다.

### WO-MKT-013: FAQ 페이지 생성

INV-MKT-001의 9가지 기본 질문형 기반 FAQ 페이지를 생성한다.

PASS: Schema.org FAQPage 구조화 데이터가 적용된다.

---

## Phase 4: 전환 자동화

### WO-MKT-014: PQL 판정 기준

진단 완료 + 결과 열람 + 이메일 등록 또는 재방문 조건으로 PQL을 판정한다.

PASS: PQL 조건 충족 시 자동 태그가 부여된다.

### WO-MKT-015: 이메일 시퀀스

PQL 대상에게 진단 결과 요약, 추가 분석 제안, 상담 안내를 자동 발송한다.

PASS: 이메일이 PQL 판정 후 자동 발송된다.

### WO-MKT-016: 상담 자동 연결

높은 PQL 점수 대상에게 상담 예약 페이지를 안내한다.

PASS: 상담 예약이 자동으로 연결된다.

## 작업 순서 (권장)

```
WO-MKT-001 (API) → WO-MKT-002~004 (법령 페이지) → WO-MKT-005 (SEO)
→ WO-MKT-006 (CTA) → WO-MKT-007~009 (무료진단) → WO-MKT-010 (행동 데이터)
→ WO-MKT-011~013 (SEO 콘텐츠) → WO-MKT-014~016 (전환 자동화)
```

## 측정 기준 (Phase별)

Phase 1: 검색 노출 수, 페이지 유입 수, 체류 시간.
Phase 2: 진단 시작 수, 완료 수, 결과 열람 수, 이메일 등록 수.
Phase 3: 검색 유입 페이지 수, 총 유입 수, 진단 연결 수.
Phase 4: PQL 수, 상담 전환 수, 유료 전환 수.
