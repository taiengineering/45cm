## 해결책 요약

P1~P5 문제에 대해 3가지 해결 수단을 설계한다.

### 수단 1: 법령검색 페이지 (P1 발견 + P4 신뢰)

TAI 웹사이트에 산업안전 법령을 검색할 수 있는 페이지를 만든다. 고객이 검색엔진에서 법령/의무/점검/처벌 등을 검색할 때 TAI 페이지가 노출된다. 법령 근거, 조문, 출처, 시행일을 표시하여 신뢰를 확보한다. 법령엔진의 정확한 데이터를 기반으로 한다.

### 수단 2: 무료진단 셀프서비스 (P2 경험 + P3 전환)

방문자가 KSIC/시설/설비/공정/작업을 입력하면 즉시 Applicable Obligation 결과를 확인할 수 있다. 회원가입 없이 시작, 결과 일부를 보여주고 전체 결과는 이메일/가입 후 제공. 행동 데이터를 수집하여 PQL 판정.

### 수단 3: SEO 콘텐츠 (P1 발견 + P4 신뢰 + P5 자동화)

고객이 반복적으로 검색하는 10가지 수요군(INV-MKT-007)에 대응하는 페이지를 법령엔진 데이터 기반으로 자동 생성한다. 법령 개정 시 자동 업데이트. 1인 운영이 가능한 구조.

### P5 해결: 자동화 구조

법령 데이터 기반 콘텐츠 자동 생성, 행동 데이터 기반 PQL 자동 판정, 후속 접촉 자동화(이메일 시퀀스), 법령 개정 시 콘텐츠 자동 업데이트.
