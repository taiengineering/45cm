## 1. 현재 단계

지금은 AI 사용 여부를 정할 단계가 아니라, 질문 처리 로직을 정의할 단계이다. 특정 기술을 정하지 않고 입력과 출력의 판정 규칙만 고정한다.

---

## 2. 현재 로직

```
웹 디스커버리
    ↓
검색어·질문 후보 수집
    ↓
핵심어와 검색 의도 식별
    ↓
동일 의미 질문 판별
    ↓
표현 변형
    ↓
질문엔진 가동
    ↓
답변 생성
    ↓
SEO 처리
    ↓
웹 게시
```

---

## 3. 핵심: 두 작업의 분리

### 3.1 동일 의미 질문의 표현 변형

원본: 소방안전관리자 선임 기준

허용되는 변형:

- 소방안전관리자 선임 기준은 무엇인가요?
- 소방안전관리자 선임 기준이 어떻게 되나요?
- 소방안전관리자 선임기준 알려주세요.

`소방안전관리자 + 선임 + 기준`이라는 의미 단위가 모두 유지된다.

### 3.2 다른 검색 의도의 별도 질문 발견

- 소방안전관리자 선임 대상
- 소방안전관리자 선임 시기
- 소방안전관리자 선임 절차
- 소방안전관리자 미선임 처벌

이것들은 원본 질문의 변형이나 확장이 아니라 각각 독립된 질문 후보이다. 웹에서 실제 수요가 발견됐을 때 별도로 등록해야 한다.

---

## 4. 질문 처리의 기본 규칙

```
원본 검색어
    ↓
핵심 대상 추출: 소방안전관리자
    ↓
행위 추출: 선임
    ↓
의도 추출: 기준
    ↓
세 요소를 보존한 표현만 동일 질문으로 인정
```

**판정 규칙**: 질문의 대상·행위·의도를 보존하면 표현 변형이고, 하나라도 달라지면 별개의 질문이다.

---

## 5. 기술 중립

AI는 이 로직을 실행하는 수단 중 하나일 뿐이다. 규칙 기반 처리, 검색 API, 사전 매핑, 사람 검토로도 구현할 수 있다. 기획 단계에서는 특정 기술을 정하지 않고 입력과 출력의 판정 규칙만 고정한다.
