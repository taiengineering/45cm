## 목적

고객이 반복적으로 검색하는 10가지 수요군(INV-MKT-007)에 대응하는 페이지를 법령엔진 데이터 기반으로 생성한다. 법령 개정 시 자동 업데이트. 1인 운영 가능.

## 대상 수요군 (INV-MKT-007 기반)

(1) 법적 의무 확인, (2) 해야 하는 일, (3) 시기/주기, (4) 책임자, (5) 처벌, (6) 교육, (7) 위험성평가, (8) 중대재해처벌법, (9) 서류/서식, (10) 사고 대응.

## 페이지 유형

의무 해설 페이지: "안전관리자 선임 대상", "위험성평가 실시 방법" 등. 법령엔진 데이터에서 자동 생성.

FAQ 페이지: INV-MKT-001에서 확인된 9가지 기본 질문형 기반. "누가 해야 하나?", "우리도 대상인가?" 등.

체크리스트 페이지: 점검항목, 교육항목, 서류 목록 등.

## 자동화 구조

법령엔진 DB → 템플릿 기반 페이지 생성 → 법령 개정 시 DB 업데이트 → 페이지 자동 재생성. 사람이 하는 일: 템플릿 설계, 품질 검수. 시스템이 하는 일: 데이터 추출, 페이지 생성, sitemap 갱신.

## SEO 요소

title/description/canonical, Schema.org FAQPage/HowTo, sitemap.xml 자동 갱신, 내부 링크(법령→의무→진단), 출처 표시.

## 연결

모든 콘텐츠 페이지에서 무료진단 CTA로 연결. "우리 사업장에 해당되는지 확인하기" 버튼.
