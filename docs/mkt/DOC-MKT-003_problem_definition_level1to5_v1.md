## 1. 문서 목적

본 문서는 위 목표의 달성을 방해하는 문제를 추상 수준에서 구체 수준으로 분해하여 정의한다. 조사·분석 결과를 근거로 문제만 선언하며, 해결책·채널 전략·엔진·기획안은 포함하지 않는다.

## 2. 문제정의 원칙

- 문제는 목표 달성을 방해하는 상태로 표현한다.
- 사실이나 관찰을 그대로 문제로 쓰지 않고, 목표와의 관계를 분명히 한다.
- 상위 문제와 하위 문제의 인과·포함 관계가 추적 가능해야 한다.
- Level 4와 Level 5는 경로와 채널의 존재를 나열하는 것이 아니라, 그 경로와 채널에서 나타나는 문제를 정의한다.
- 문제정의 단계에서는 해결 방법을 제시하지 않는다.

## 3. 문제정의 체계

| Level | 명칭 | 핵심 질문 | 정의 범위 |
|---|---|---|---|
| 1 | 전략 문제 | 목표를 방해하는 가장 큰 문제는 무엇인가? | 전체 시장과 TAI의 관계 |
| 2 | 영역 문제 | 전략 문제는 어떤 문제 영역으로 구성되는가? | 발견·이해·신뢰·선택 등 |
| 3 | 구조 문제 | 각 영역을 만드는 구조적 원인은 무엇인가? | 사용자 행동·언어·정보·판단 구조 |
| 4 | 경로 문제 | 어떤 만남 경로에서 문제가 발생하는가? | 검색·AI·커뮤니티·협회·정부·거래 관계 등 |
| 5 | 채널 문제 | 구체 채널에서 어떤 문제가 나타나는가? | Google·네이버·ChatGPT 등 개별 채널 |

## 4. TAI 문제정의

### Level 1. 전략 문제

**P1. 시장은 TAI를 찾지 않는 상태에서 TAI를 만나지 못한다.**

목표는 사용자의 능동적 탐색 없이도 TAI와의 만남이 발생하는 상태다. 현재는 그러한 만남이 자연스럽게 발생하지 않는 것이 최상위 문제다.

### Level 2. 영역 문제

- **P1-1 발견 문제:** 사용자의 일상적 업무 행동 안에서 TAI가 발견되지 않는다.
- **P1-2 관련성 문제:** TAI가 사용자의 현재 업무 문제와 연결된 존재로 인식되지 않는다.
- **P1-3 이해 문제:** 사용자는 TAI가 무엇을 해결하는지 즉시 이해하지 못한다.
- **P1-4 신뢰 문제:** 사용자는 TAI의 판단과 결과를 신뢰할 근거를 충분히 만나지 못한다.
- **P1-5 선택 문제:** TAI를 알게 되더라도 현재 행동을 멈추고 TAI를 선택해야 할 이유가 분명하지 않다.

### Level 3. 구조 문제

**P1-1 발견 문제의 구조**

- 사용자는 TAI라는 서비스명을 전제로 행동하지 않는다.
- 사용자는 자신의 업무, 설비, 법령, 점검, 사고, 처벌과 관련된 질문과 과업을 중심으로 움직인다.
- TAI의 존재가 사용자의 실제 업무 흐름과 질문 구조에 연결되어 있지 않다.
- 사용자가 쓰는 표현과 TAI가 자신을 설명하는 표현 사이에 간극이 있다.

**P1-2 관련성 문제의 구조**

- 사용자의 현재 상황과 TAI의 기능 사이의 연결 관계가 즉시 드러나지 않는다.
- 사용자는 자신의 상황이 TAI의 대상인지 판단하기 어렵다.
- TAI가 일반 정보인지, 진단인지, 실행 지원인지 역할이 명확하게 구분되어 인식되지 않는다.

**P1-3 이해 문제의 구조**

- TAI의 가치가 기능 설명 중심으로 전달되면 사용자의 문제 언어와 맞지 않는다.
- 사용자가 얻는 결과와 변화가 한 번에 이해되는 구조가 부족하다.
- 대상·입력·판단·결과의 관계가 사용자 관점에서 단순하게 정리되어 있지 않다.

**P1-4 신뢰 문제의 구조**

- 법적·기술적 판단의 근거와 한계가 사용자가 확인할 수 있는 형태로 드러나지 않는다.
- 결과의 출처, 적용 조건, 최신성, 검증 여부가 신뢰 판단에 필요한 수준으로 연결되어 있지 않다.
- 서비스의 주장보다 사용자가 스스로 확인할 수 있는 증거 구조가 부족하다.

**P1-5 선택 문제의 구조**

- 기존 방식과 비교했을 때 TAI를 선택해야 하는 차이가 즉시 드러나지 않는다.
- 사용 시작에 필요한 시간·정보·행동 부담이 불명확하다.
- 첫 경험에서 얻는 실질적 결과가 선택 결정을 촉진할 만큼 선명하게 제시되지 않는다.

### Level 4. 경로 문제

사용자가 TAI를 직접 찾지 않아도 만날 가능성이 있는 경로별 문제는 다음과 같다.

| 경로 | 정의된 문제 |
|---|---|
| 검색 경로 | 사용자가 업무 질문을 검색해도 TAI와 연결되는 정보 구조가 충분하지 않다. |
| AI 경로 | 사용자가 AI에 업무 질문을 해도 TAI가 신뢰 가능한 해결 자원으로 연결되지 않는다. |
| 커뮤니티 경로 | 동종 업계의 경험과 질문이 오가는 공간에서 TAI가 문제 해결의 기준점으로 등장하지 않는다. |
| 협회·교육 경로 | 전문기관의 교육과 자료 흐름 속에서 TAI가 실무 도구로 연결되지 않는다. |
| 정부·공공 경로 | 법령·행정·점검 정보를 확인하는 흐름과 TAI의 진단 경험이 이어지지 않는다. |
| 거래 관계 경로 | 검사기관·설비업체·협력사와의 업무 과정에서 TAI가 공동 판단 도구로 등장하지 않는다. |
| 미디어·콘텐츠 경로 | 사고·규제·점검 이슈를 접한 뒤 TAI로 이어지는 연결이 형성되어 있지 않다. |
| 오프라인 경로 | 현장, 세미나, 박람회, 소개 과정에서 TAI를 즉시 경험하거나 확인할 수 있는 접점이 부족하다. |

### Level 5. 채널 문제

채널 문제는 개별 채널에서 TAI가 단순히 "없다"는 뜻이 아니라, 사용자의 질문·정보 탐색·신뢰 형성 흐름 속에서 TAI가 유효한 답 또는 다음 행동으로 연결되지 않는 상태를 뜻한다.

| 경로 | 대표 채널 | 채널 문제 |
|---|---|---|
| 검색 | Google, 네이버, Bing | 사용자의 업무 질문과 TAI의 정보가 연결되지 않거나, 연결되더라도 관련성과 신뢰가 충분히 전달되지 않는다. |
| 생성형 AI | ChatGPT, Claude, Gemini, Perplexity | 사용자의 질문에 대한 답변 과정에서 TAI가 근거 있는 진단 자원 또는 다음 단계로 제시되지 않는다. |
| 영상·소셜 | YouTube, LinkedIn, Facebook, Instagram | 이슈 인지 후 TAI의 가치 이해와 실제 경험으로 이어지는 흐름이 단절되어 있다. |
| 커뮤니티 | 네이버 카페, 카카오 오픈채팅, 업계 커뮤니티 | 반복되는 실무 질문과 TAI의 해결 역량이 연결되지 않는다. |
| 공공·전문기관 | 정부 포털, KOSHA, 협회, 교육기관 | 기준 확인과 실제 진단·적용 사이에서 TAI가 보완 도구로 인식되지 않는다. |
| 거래·현장 | 검사기관, 설비업체, 협력사, 박람회 | 현장의 문제 발생 시 TAI를 공동 판단 수단으로 사용하거나 소개하는 구조가 없다. |

## 5. 최종 문제문

> TAI의 핵심 문제는, 사용자가 TAI를 직접 찾지 않는 상태에서 자신의 업무 문제를 해결하기 위해 이동하는 경로와 채널 안에 TAI가 발견·이해·신뢰·선택 가능한 형태로 연결되어 있지 않다는 것이다.

## 6. 문제정의 범위 종료

본 문서는 Level 1부터 Level 5까지의 문제를 정의한 것으로 종료한다. 이후 단계에서 다룰 내용은 해결 우선순위, 경로별 전략, 채널별 실행, 콘텐츠, 제품 기능, 데이터 구조, 엔진 및 운영 설계다. 이 항목들은 본 문제정의서에 포함하지 않는다.
