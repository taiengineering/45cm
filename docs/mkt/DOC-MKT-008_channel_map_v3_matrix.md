## 3축 좌표계

### X축: 어디에서 만나는가? (채널)

검색, AI, 영상, 커뮤니티, SNS, 메신저, 기관, 협회, 오프라인, 업무시스템

### Y축: 무엇을 하러 왔는가? (목적)

법령 확인, 의무 확인, 선임 확인, 점검 확인, 과태료 확인, 사례 확인, 계산, 체크리스트, 양식, 교육, 제품, 업체, 전문가, 무료진단

이 축은 계속 확장된다.

### Z축: 어떤 방식으로 소비하는가? (콘텐츠)

질문, 답변, 블로그, 영상, 이미지, 표, PDF, 체크리스트, 계산기, 법령, 사례, FAQ, 뉴스

---

## 좌표 예시

| X | Y | Z |
|---|---|---|
| Google | 법령 확인 | FAQ |
| Google | 법령 확인 | 블로그 |
| ChatGPT | 의무 확인 | 질문/답변 |
| YouTube | 교육 | 영상 |
| 카페 | 사례 확인 | 게시글 |
| KOSHA | 체크리스트 | PDF |

모든 채널을 동일한 구조로 표현할 수 있다.

---

## 빠진 좌표 찾기 (White Space)

좌표계가 만들어지면 빠진 좌표를 찾는 작업이 핵심이다.

Google × 법령 확인 × FAQ → 있다.

Google × 법령 확인 × 계산기 → 거의 없다.

ChatGPT × 체크리스트 × PDF → 있다.

비어 있는 영역(White Space)이 보인다.

---

## 우리가 만드는 것은 채널 지도가 아니다

콘텐츠가 존재하는 공간의 지도이다.

```
Google
├─ 법령
├─ FAQ
├─ 사례
├─ 계산기
├─ 체크리스트
└─ 양식
```

여기서 무엇이 비어 있는지가 바로 TAI가 채워야 할 영역이다.

## 채널 매트릭스 (첫 번째 지도)

| 채널 | 법령 | FAQ | 사례 | 계산기 | 체크리스트 | 양식 | 영상 |
|---|---|---|---|---|---|---|---|
| Google | ✓ | ✓ | ✓ | △ | ✓ | △ | △ |
| 네이버 | ✓ | ✓ | ✓ | × | ✓ | ✓ | △ |
| ChatGPT | ✓ | ✓ | △ | ✓ | ✓ | ✓ | × |
| YouTube | △ | △ | ✓ | × | ✓ | × | ✓ |
| KOSHA | ✓ | ✓ | △ | × | ✓ | ✓ | × |

이 매트릭스가 완성되면 단순한 목록이 아니라 "어디에 어떤 팻말이 이미 있고, 어디가 비어 있는가"를 한눈에 볼 수 있다.
