## 1. 마케팅은 두 종류뿐이다

```
1. 기다리는 마케팅 (Passive) — 팻말을 세우고 고객이 오기를 기다린다
2. 찾아가는 마케팅 (Active) — 우리가 먼저 고객을 찾아간다
```

Passive는 DOC-MKT-006~010에서 설계 완료. 이제 Active를 설계한다.

---

## 2. Active Marketing 기본 흐름

```
대상 발굴 → 대상 선별 → 접촉 → 관심 유도 → 무료진단 → 관계 유지
```

### 2.1 대상 발굴

고객을 찾는다. 아직 연락하지 않는다.

산업단지, 공장, 건설현장, 빌딩, 병원, 학교, 물류센터

### 2.2 대상 선별

찾은 대상 중 우선순위를 정한다.

업종, 규모, 종업원수, 위험도, 지역, 관리주체

### 2.3 접촉

접촉 채널: 이메일, 전화, 문자, 카카오톡, LinkedIn, 협회, 세미나, 방문, 소개, DM

### 2.4 관심 유도

팻말을 직접 전달한다.

무료진단, 체크리스트, 법령 변경, 과태료 안내, 교육자료, 점검표, 뉴스레터

### 2.5 무료진단

TAI로 연결된다.

### 2.6 관계 유지

메일, 뉴스레터, 법령 변경, 월간 리포트, 점검 알림, 교육 안내

---

## 3. 접촉 방식은 네 가지뿐이다

### 내가 찾는다

기업검색, 공장검색, 산업단지검색

### 내가 보낸다

이메일, 문자, DM, 우편

### 내가 만난다

전화, 방문, 전시회, 협회, 세미나

### 누군가 소개한다

추천, 파트너, 협회, 기존고객, 지인

---

## 4. Active의 핵심 객체는 대상(Target)이다

Passive에서는 채널이 중심이었다. Active에서는 모든 것이 대상을 중심으로 움직인다.

```
대상
 ├ 기업
 ├ 공장
 ├ 담당자
 ├ 연락처
 ├ 업종
 ├ 규모
 ├ 지역
```

이 대상 하나에 대해 다음이 모두 연결된다:

- 어떤 방식으로 발견했는지
- 어떤 채널로 접촉했는지
- 어떤 자료를 보냈는지
- 무료진단을 했는지
- 이후 어떤 관계를 유지하고 있는지

---

## 5. TAI 전체 마케팅 아키텍처

```
Passive = 길 중심 (Map of Paths)
  길 → 교차로 → 팻말 → 목적지(무료진단)

Active = 대상 중심 (Map of Targets)
  대상 발굴 → 선별 → 접촉 → 관심 → 무료진단 → 관계
```

이 둘이 합쳐져야 TAI의 전체 마케팅 아키텍처가 완성된다.

```
              ┌─── Passive (길 중심) ───┐
              │ 길 → 교차로 → 팻말      │
              │         ↓               │
              │     무료진단             │
              │         ↑               │
              │ 대상 → 접촉 → 관심      │
              └─── Active (대상 중심) ───┘
```

무료진단이 Passive와 Active의 합류 지점이다.
