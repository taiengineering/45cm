> 제외: TAI 적용, UI 설계, 브랜딩 전략

확인된 신뢰 요소 11가지: (1) 법령 근거 제시(조문, 시행령, 시행규칙, 고시, KOSHA GUIDE), (2) 조문 표시, (3) 최신 시행일(법령 개정이 잦아 최신성 자체가 신뢰 요소), (4) 공식 출처(국가법령정보센터, 고용노동부, 안전보건공단, 정부24, 1350, 대한산업안전협회), (5) 원문 연결(요약만 제공하지 않고 원문 보기/관련 조문 이동/별표 보기 등), (6) 복수 출처 표시, (7) 실제 사례(2026년 중대재해 재해조사보고서 공개 시작), (8) 운영 사례(안전보건공단 상생협력활동 사례 100선), (9) 전문가 참여(안전보건공단, 연구기관, 학회, 컨설턴트), (10) 한계 명시("참고자료입니다", "최종 판단은 현행 법령 확인", "개별 사업장에 따라 다를 수 있음"), (11) 투명한 근거 제시(AI가 어떤 근거로 답했는지 보여주는 방향).

신뢰 구조: 최신 정보 + 공식 근거 + 출처 공개 + 원문 확인 + 실제 사례 + 투명한 설명 = 신뢰 형성.

미확인: 사업주가 가장 신뢰하는 출처 순위, 무료 vs 유료 서비스 신뢰도 차이, AI 답변 vs 전문가 답변 신뢰도 비교, 구매 결정 시 가장 영향력 큰 신뢰 요소.
