## 고객 행동 기준 분류

채널을 플랫폼 기준이 아니라 고객 행동 기준으로도 분류해야 한다.

| 고객 행동 | 실제 채널 |
|---|---|
| 검색한다 | Google, 네이버, ChatGPT Search |
| 질문한다 | 지식인, Reddit, 카페, GPT |
| 공부한다 | YouTube, 협회교육, 블로그 |
| 법령을 찾는다 | 국가법령정보센터, KOSHA |
| 동료에게 묻는다 | 카카오톡, Slack, 오픈채팅 |
| 전문가를 찾는다 | 협회, 기술사 모임, 세미나 |
| 제품을 찾는다 | 제조사 홈페이지, 쇼핑몰, 전시회 |

이 분류가 중요한 이유는 콘텐츠 전략이 아니라 고객 행동 전략으로 바뀌기 때문이다.

## 다음 단계 제안

아직 운영방식으로 넘어가지 않고, 채널맵을 완성하는 것이 좋다. 채널마다 아래 5개의 속성만 추가하면 이후 기획이 매우 쉬워진다.

| 항목 | 설명 |
|---|---|
| 고객 유형 | 누가 이용하는가 (안전관리자, 공장장, 대표 등) |
| 이용 목적 | 왜 오는가 (검색, 질문, 학습, 상담 등) |
| 참여 방식 | 읽기, 질문, 답변, 게시, 공유 |
| 영향력 | 고객 유입에 얼마나 중요한가 |
| 운영 가능성 | 현재 1인 체계에서 운영 가능한가 |

이렇게 하면 이후에는 운영방식, 자동화, 콘텐츠 공급을 모두 이 채널맵을 기준으로 설계할 수 있다. 이는 단순한 채널 목록이 아니라, TAI의 고객 접점 아키텍처가 될 것이다.
