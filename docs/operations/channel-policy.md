# Channel Operating Policy

## LinkedIn

| 항목 | 기준 |
|------|------|
| 빈도 | 주 2-3회 |
| 톤 | 전문성 중심, 인사이트형 |
| CTA | Soft CTA 기본 (Hard CTA는 전환 캠페인만) |
| 최적 시간 | 화/목 오전 8-10시 |
| Visual | TAI Professional 프리셋 |
| 금지 | 과도한 이모지, 개인적 톤, 광고성 |

## Facebook

| 항목 | 기준 |
|------|------|
| 빈도 | 주 1회 |
| 톤 | 친근한 대화형 |
| CTA | Soft CTA만 |
| 최적 시간 | 수요일 오후 2-4시 |
| Visual | Clean Corporate 프리셋 |
| 금지 | 장문 콘텐츠, 기술 용어 과다 |

## Naver Blog

| 항목 | 기준 |
|------|------|
| 빈도 | 주 1-2회 |
| 톤 | 정보형 + SEO 최적화 |
| CTA | Advisory CTA (전문가 상담) |
| 최적 시간 | 월/수 오전 |
| Visual | Blog Cover 프리셋 |
| 금지 | 키워드 스태킹, 과도한 볼드 |

## Naver 지식인

| 항목 | 기준 |
|------|------|
| 빈도 | 수시 (키워드 기반 수집) |
| 톤 | 전문가 답변 느낌 |
| CTA | 최소 (자연스러운 참고 링크만) |
| Anti-AI | 최대 강도 |
