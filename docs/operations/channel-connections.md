# Channel Connection Playbook

## LinkedIn 연결 방법

### 1단계 — Connect 버튼 클릭
```
app.45cm.com/settings
→ LinkedIn 카드
→ Connect 버튼
```

### 2단계 — LinkedIn 로그인
LinkedIn 계정으로 로그인합니다.

### 3단계 — 권한 승인
"Allow" 버튼을 눌러 다음 권한을 승인합니다:
- 프로필 읽기
- 게시물 작성

### 4단계 — 연결 완료
Settings 페이지로 돌아오며 "✓ Connected" 상태가 표시됩니다.

### Test Connection
Connect 후 "Test" 버튼을 눌러 게시 가능 여부를 확인하세요.

## 문제 해결

### "연결이 만료되었습니다"
Settings → 해당 채널 → **Reconnect** 클릭

### "게시 권한이 없습니다"
1. 해당 채널 개발자 앱에서 권한 확인
2. Reconnect로 권한 재승인

### "Test에서 실패"
1. 토큰 만료 여부 확인
2. Reconnect 시도
3. 채널 개발자 앱 상태 확인

### "연결 버튼이 안 됩니다"
- 사용 중인 브라우저에서 팝업 차단 해제
- 다른 브라우저에서 시도
