# Approval Policy

## 승인 필요 기준

| 조건 | 승인 필요 여부 |
|------|-------------|
| Hard CTA (강도 4-5) | ✅ 필수 |
| 법률/규제 관련 콘텐츠 | ✅ 필수 |
| 새 캠페인 첫 콘텐츠 | ✅ 필수 |
| 민감한 사례 언급 | ✅ 필수 |
| FAQ/일반 정보 | ⭕ 자동 승인 가능 |
| 기존 캠페인 반복 콘텐츠 | ⭕ 자동 승인 가능 |

## 승인 흐름

```
Draft 생성
→ Slack 승인 요청
→ 운영자 검토
→ Approve / Reject
→ Publish 가능 / 수정 필요
```

## 승인 SLA

- 일반 콘텐츠: 4시간 이내
- 긴급 콘텐츠: 1시간 이내
- 24시간 미처리: 자동 알림

## 승인 거절 시

- 거절 사유 기록
- Draft 수정 후 재요청
- 같은 Draft 최대 3회 재요청
