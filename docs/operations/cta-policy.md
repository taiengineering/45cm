# CTA Operating Policy

## CTA 유형

| 유형 | 강도 | 예시 | 사용 상황 |
|------|------|------|----------|
| Soft | 1-2 | 참고해보세요, 문의해주세요 | 일반 콘텐츠 |
| Advisory | 3 | 전문가 상담을 받아보세요 | 교육/정보 콘텐츠 |
| Hard | 4-5 | 지금 바로 무료 진단 신청! | 전환 캠페인만 |

## CTA 운영 규칙

1. 모든 콘텐츠에 CTA를 넣지 않는다
2. 한 채널에서 연속 3개 이상 Hard CTA 금지
3. CTA 전환율이 하락하면 강도를 낮춘다
4. 브랜딩 캠페인은 Soft CTA만 사용
5. CTA 피로도는 Campaign Intelligence에서 주기적 확인

## CTA 전환 목표

| CTA | 목표 |
|-----|------|
| 무료 법령진단 | 리드 생성 |
| 체크리스트 다운로드 | 이메일 수집 |
| 전문가 상담 | 직접 전환 |
| 자료 요청 | 리드 생성 |

## 엔진 경계

CTA 클릭 → 리드 생성까지 Marketing Engine.
리드 처리 → 고객 관리는 관재엔진.
