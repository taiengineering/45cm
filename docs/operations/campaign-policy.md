# Campaign Operating Policy

## Campaign Lifecycle

| 상태 | 설명 |
|------|------|
| active | 운영 중 — 콘텐츠 생성/발행 가능 |
| paused | 일시 중지 — 발행 중단, 데이터 유지 |
| completed | 목표 달성 후 종료 |
| archived | 영구 보관 |

## Campaign Goals

모든 캠페인은 반드시 하나의 목표를 가진다.

| 목표 유형 | 예시 |
|----------|------|
| 인지도 | 중대재해처벌법 인지도 향상 |
| 전환 | 무료 법령진단 신청 |
| 교육 | 안전관리자 실무 가이드 |
| 브랜딩 | TAI Engineering 전문성 확립 |

## Channel Usage Policy

| 채널 | 용도 | 빈도 |
|------|------|------|
| LinkedIn | B2B 전문성 + CTA | 주 2-3회 |
| Naver Blog | 정보형 + SEO | 주 1-2회 |
| Facebook | 친근한 인사이트 | 주 1회 |
| 지식인 | 전문가 답변 | 수시 |

## CTA Policy

- 모든 콘텐츠에 Hard CTA 금지
- LinkedIn: Soft CTA 중심 (참고해보세요)
- 전환 목적 캠페인만 Hard CTA 허용
- CTA 피로도 주기적 점검

## Approval Policy

| 콘텐츠 유형 | 승인 |
|------------|------|
| FAQ/정보형 | 자동 승인 가능 |
| CTA 포함 | 수동 승인 필수 |
| 법률 관련 | 수동 승인 필수 |
| 캠페인 시작 | 수동 승인 필수 |

## Publish Rhythm

- 월~금 운영 (주말 발행 금지)
- 오전 8~10시 최적
- 하루 최대 2개
- 채널 간 최소 2시간 간격
