# Operator Daily Workflow

## 1. 출근 — Dashboard 확인 (5분)

```
app.45cm.com/dashboard
```

확인 항목:
- 승인 대기 건수
- 발행 실패 건수
- 오늘 예약 게시
- 어제 CTA 클릭

## 2. 승인 처리 (10분)

Slack 또는 Dashboard에서 승인/거절.
법률 콘텐츠는 반드시 내용 검토.

## 3. 오늘 예약 점검 (5분)

```
app.45cm.com/calendar
```

- 예약 시간 확인
- 채널 확인
- Visual 확인

## 4. Draft 검토 (15분)

```
app.45cm.com/drafts
```

- Humanize 결과 확인
- AI 냄새 점검
- Brand Voice 일관성 확인

## 5. 발행 확인 (5분)

- Published 상태 확인
- 실패 시 원인 파악
- Timeline 확인

## 6. 퇴근 전 — 반응 확인 (5분)

```
app.45cm.com/channels
app.45cm.com/intelligence
```

- CTA 클릭 수
- Engagement 변화
- Channel Health 변화

## 주간 (금요일)

- Strategy Memory에 주간 메모 작성
- Campaign Intelligence 리뷰
- 다음 주 발행 계획 확인
