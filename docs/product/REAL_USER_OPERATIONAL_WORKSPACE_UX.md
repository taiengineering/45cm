# 한국형 Operational Workspace UX

## 철학

```
운영자는 시스템을 배우고 싶어하지 않는다.
오늘 해야 할 것, 위험한 것, 승인할 것을
직관적으로 이해하고 싶어한다.
```

## 핵심 변경

| Before | After |
|--------|-------|
| Sidebar 중심 | Top Navigation |
| 영어 용어 | 한국어 사람 언어 |
| 차트 중심 | 액션 중심 |
| 기술 용어 | 운영 언어 |
| Dashboard | Today Feed |
| 복잡한 테이블 | 카드 UI |
| 차가운 SaaS | Warmth Workspace |

## Top Navigation

| 메뉴 | 역할 |
|------|------|
| 홈 | 오늘 피드 + 상태 |
| 스튜디오 | 콘텐츠/쇼츠/미리보기 |
| 승인함 | 검토 대기열 |
| 채널상태 | Surface 건강도 |
| 운영흐름 | Lifecycle |
| 이벤트 | 이벤트 운영 |
| 패턴 | 브랜드 패턴 |
| 자산 | 브랜드 자산 |
| 메모리 | 운영 기억 |
| 제어 | Auto/Assisted/Manual |
| 설정 | 채널 연동 |

## 사람 언어 변환

| Runtime | 한국어 UI |
|---------|--------|
| fatigue | 너무 자주 올리고 있어요 |
| surface imbalance | 블로그 운영이 부족해요 |
| trust decay | 광고 느낌이 강해지고 있어요 |
| cadence unstable | 운영 리듬이 불안정해요 |
| overloaded | 운영량이 많아지고 있어요 |
| CTA pressure | CTA 비율이 너무 높아요 |
| dormant | 오래 업데이트 없어요 |
| recovery | 쉬는 것이 좋아요 |

## Warmth UX

- 시간대별 인사: "좋은 아침입니다" / "오후도 파이팅" / "수고하셨습니다"
- 상태 표현: "오늘 운영은 안정적입니다"
- 마무리: "오늘도 좋은 운영 되세요 🙌"

## Mobile UX

필수 모바일 최적화:
- 승인/거절 버튼
- Feed 확인
- 이벤트 확인
- 긴급 중단

## 금지 용어 (UI)

fatigue, surface, routing, cadence, trust decay, pattern lifecycle,
runtime, tenant, middleware, webhook, scope, token

## 금지 UI

복잡한 그래프 과다, 개발자 용어, AI 모델 설명, 기술적 Runtime 표현
