# 45cm SaaS Product Architecture
## Healthy Operational Marketing Platform

---

# 1. Product Definition

45cm는:

- AI 콘텐츠 생성기
- Growth Hacking Tool
- 공격형 마케팅 자동화 시스템

이 아니다.

45cm는:

# “브랜드를 망치지 않으면서 지속 가능한 운영을 가능하게 하는 Brand Operations Platform”

이다.

---

# 2. Core Product Philosophy

45cm의 핵심은:

```text
더 많이 생성
```

이 아니라,

```text
더 건강하게 운영
```

이다.

우리는:

- 과발행
- 콘텐츠 공장화
- 복붙 운영
- aggressive CTA
- AI 폭주
- growth addiction

을 지양한다.

우리는:

- cadence
- trust
- sustainability
- brand safety
- operational stability

를 중심으로 설계한다.

---

# 3. Product Positioning

45cm는:

# Healthy Operational Marketing Platform

또는:

# Brand Operations System

으로 정의된다.

핵심 목적은:

- 브랜드 운영 안정화
- 채널 건강성 유지
- 콘텐츠 균형 유지
- 운영 피로 감소
- 장기 브랜드 신뢰 축적

이다.

---

# 4. Core Operating Principles

| 원칙 | 의미 |
|---|---|
| Healthy Cadence | 무리하지 않는 운영 |
| Human-first AI | AI는 조언만 |
| Brand Safety | 브랜드 보호 |
| Operational Sustainability | 장기 운영 가능성 |
| Anti Content Factory | 복붙/과생성 방지 |
| Channel Health | 채널 상태 유지 |
| Sustainable Performance | 장기 퍼포먼스 |
| Consumer Respect | 소비자가 싫어하지 않는 상태 |
| Operator-first | 운영자 burnout 감소 |
| Guidance over Automation | 자동화보다 운영 보조 |

---

# 5. Workspace Architecture

## 기본 구조

```text
1 Workspace = 1 Brand
```

이 구조를 기본 원칙으로 한다.

이유:

- cadence
- fatigue
- trust
- CTA pressure
- tone
- channel health

가 모두 브랜드 단위로 동작하기 때문이다.

---

## Agency 구조

```text
Agency Account
 └ Workspace A
 └ Workspace B
 └ Workspace C
```

광고대행사는 여러 브랜드 Workspace를 관리한다.

---

# 6. Core Product Areas

| 영역 | 역할 |

| Operations | 승인/발행/일정 운영 |

# 7. Home Philosophy

Home은:

```text
Analytics Dashboard
```

가 아니라,

# Operational Control Surface

이어야 한다.

사용자는:

- 오늘 위험한 게 무엇인지
- 무엇을 쉬어야 하는지
- 어떤 흐름이 부족한지
- 어떤 채널이 unhealthy한지

를 즉시 이해해야 한다.

# 11. Content Mix Philosophy

좋은 브랜드는:

- 다양한 콘텐츠 흐름을 가지며
- 모든 게시물이 CTA가 아니고
- 운영 흔적이 존재하며
- 사람 느낌이 살아있어야 한다.

45cm는:

# Content Operating Mix

를 관리한다.

예:

| 유형 | 비율 |
|---|---|
| Brand | 20% |
| Insight | 20% |
| Trust | 15% |
| Operations | 10% |
| CTA | 10% |
| FAQ | 5% |

---

# Channel Health

구성 요소:

# 14. Calm Behavioral Design

45cm는:

```text
행동 압박형 SaaS
```

를 지양한다.

우리는:

- 조용한 추천
- 안정적인 운영
- calm UX
- minimal interruptions

을 지향한다.

---

# 15. Recommendation Tone

금지:

```text
더 많이 게시하세요!
CTR을 위해 CTA를 늘리세요!
```

권장:

```text
현재 cadence는 안정적인 상태입니다.
```

```text
다음 콘텐츠는 Trust 계열이 자연스럽습니다.
```

```text
최근 CTA 비중이 다소 증가했습니다.
```

---

# 16. Healthy Silence

Healthy 상태에서는:

- 시스템이 조용해야 한다.
- recommendation은 최소화되어야 한다.
- unnecessary notification은 제거되어야 한다.

45cm는:

```text
계속 자극하는 SaaS
```

가 아니다.

---

# 17. Cooldown Philosophy

45cm는:

# “쉬는 것도 운영”

으로 본다.

예:

```text
최근 CTA cadence가 높았습니다.
이번 주는 Brand/Trust 중심 흐름을 추천합니다.
```

---

# 18. Operator-first Design

45cm는:

- 채널 피로
뿐 아니라,
- 운영자 피로

도 관리한다.

감지 대상:

| 요소 | 의미 |
|---|---|
| approval backlog | 과부하 |
| repetitive edits | 운영 피로 |
| excessive revisions | 혼란 |
| publish bursts | 무리 |

---

# 19. Operational Lifecycle

45cm는:

```text
가입 → 기능 사용
```

구조가 아니라,

# 브랜드 운영 생애주기

를 가진다.

---

## Lifecycle Stages

| 단계 | 목적 |
|---|---|
| Workspace Setup | 브랜드 정의 |
| Channel Connection | 채널 연결 |
| Operational Baseline | 현재 상태 분석 |
| Content Streams Setup | 콘텐츠 흐름 설정 |
| Cadence Initialization | 초기 리듬 생성 |
| Assisted Operations | AI 보조 운영 |
| Stable Operations | 안정적 운영 |
| Long-term Optimization | 장기 최적화 |

---

# 21. Anti-patterns

45cm는 다음을 지양한다:

- 무한 자동 게시
- aggressive CTA optimization
- engagement farming
- AI autonomous marketing
- 콘텐츠 대량 생산
- 불안 유도 알림
- growth addiction UX
- 복붙 운영

---

# 22. Final Product Direction

45cm는:

```text
AI Marketing Generator
```

가 아니라,

# Healthy Brand Operations Platform

이다.

우리는:

- 브랜드를 망치지 않고
- 운영을 무너지지 않게 하며
- 장기적으로 신뢰를 축적하고
- 건강한 cadence를 유지하는

운영 시스템을 만든다.
